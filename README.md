# TWIN Playground

This repository contains the Playground applications, which together demonstrate the capabilities of the ecosystem framework in a working, end-to-end environment. The playground covers a broad range of functionality, including identity management, attestation, blob storage, non-fungible tokens, auditable item graphs and streams, and verifiable credentials.

The environment is composed of a backend REST API server and a companion web interface. The API server exposes the full set of framework endpoints, while the web interface provides an interactive front-end for exploring and exercising those endpoints directly from a browser.

## Apps

- [playground-node](apps/playground-node/README.md) - A REST API server that exposes framework package APIs covering authentication, identity, attestation, blob storage, and non-fungible tokens.
- [playground-ui](apps/playground-ui/README.md) - A web interface built with Svelte that provides interactive access to the playground REST API endpoints.
